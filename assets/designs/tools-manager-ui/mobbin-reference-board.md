# STM UI Reference Board

Status: canonical URL board only. No Mobbin screenshots, images, product marks, or proprietary assets are stored in this repository.

## Design read

Reading STM as a dense desktop developer-operations product for individual developers, with an industrial/utilitarian language. The seeded soft-play direction conflicts with authority, privilege, failure, and recovery semantics, so the implementation moves to the adjacent industrial direction.

Aesthetic thesis: industrial utility for developers. Cool graphite neutrals, rare safety orange, restrained Barlow Condensed display, Source Sans 3 body, hairline-separated data surfaces, and an ownership rail derived from the product's authoritative-manager boundary.

## Implementation notes

- Adopt pattern semantics, not layouts or assets.
- Accent color is reserved for primary consent, focus, selection, and ownership continuity.
- The ownership rail is the recognizable product motif. It connects each resource to the manager or client that retains authority.
- All prototype mutation flows stop at presentation-only results.
